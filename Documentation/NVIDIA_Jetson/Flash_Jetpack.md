## Prepare the Host PC

### Install Dependencies

```bash
sudo apt-get update && \
sudo apt-get install -y abootimg \
                        binfmt-support \
                        binutils \
                        cpp \
                        device-tree-compiler \
                        dosfstools \
                        lbzip2 \
                        libxml2-utils \
                        nfs-kernel-server \
                        python3-yaml \
                        qemu-user-static \
                        sshpass \
                        udev \
                        uuid-runtime \
                        whois \
                        openssl \
                        cpio \
                        rsync \
                        zstd
```

- **Ubuntu 18.04 and below**: `sudo apt-get install -y liblz4-tool`
- **Ubuntu 20.04 / 22.04 and above**: `sudo apt-get install -y lz4`
