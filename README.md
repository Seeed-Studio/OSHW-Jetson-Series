## Overview

This project contains the open-source hardware design files for Seeed Studio's **NVIDIA Jetson hardware series** — including the `reComputer` and `reServer` carrier boards, mini PCs, and industrial computers based on **Jetson Nano, Jetson Xavier NX, Jetson Orin NX/Orin Nano, Jetson AGX Orin, and Jetson AGX Thor**.

For every product you will find its **BRD / DSN circuit design source files** (created in Cadence **Allegro 17.4**), **visualized PDF schematics**, plus the full supporting resource set: **datasheets, 3D models, mechanical drawings (DXF), user manuals, firmware, and certifications** (CE / EUDOC / FCC / KC / ROHS / REACH / UKDOC / UKCA).

## Repository Structure

```
.
├── LICENSE
├── README.md
├── reComputer Jetson carrier board/   # one folder per reComputer product
│   ├── <product>/
│   │   ├── README.md                  # product overview (for main boards)
│   │   ├── Datasheet/                 # datasheets & pin descriptions
│   │   ├── Schematic/                 # DSN sources + PDF schematics
│   │   ├── Layout/                    # BRD layout files + PDF previews
│   │   ├── 3D Model/                  # STP / STL 3D models
│   │   ├── Mechanical/                # DXF mechanical drawings
│   │   ├── Manual/                    # user manuals, assembly & reference guides
│   │   ├── Firmware/                  # firmware / driver packages
│   │   └── Certificate/               # CE / EUDOC / FCC / KC / ROHS / REACH / UKDOC / UKCA
│   └── Jetpack resource bundles       # flash & peripheral assets (per product)
└── reServer Jetson carrier board/     # one folder per reServer product
    └── <product>/                     # same structure as reComputer
```

> **Note on large files:** 3D CAD files larger than GitHub's 100 MiB per-file limit are shipped compressed as `.stp.gz` / `.step.gz` (same content, ~5–10× smaller) — e.g. `reServer Industrial J501/…/RESERVER_AGX_ORIN_CARRIER_BOARD.stp.gz` and `reComputer Robotics J601/…/reComputer_J601.step.gz`.

## Open-Hardware Design Files

The design files were prepared in Cadence **Allegro 17.4**. Per main carrier board:

- **BRD** and **PDF** files → product **`/Layout`** subdirectory
- **DSN** files → product **`/Schematic`** subdirectory
- **PDF** visualized schematics → product **`/Schematic`** subdirectory

## Product Documentation

Beyond the open-hardware design files, every product folder archives the complete supporting documentation:

- **Datasheet/** — official datasheets, pin descriptions, carrier-board specifications
- **3D Model/** — STEP / STL mechanical models of boards and mini PCs
- **Mechanical/** — DXF drawings (outline, mounting holes, connectors)
- **Manual/** — getting-started, assembly, and reference guides
- **Firmware/** — BSP / driver / flashing packages per board
- **Certificate/** — per-SKU compliance certificates (CE, EUDOC, FCC, KC, ROHS, REACH, UKDOC, UKCA)

See the [project wiki](https://wiki.seeedstudio.com/NVIDIA_Jetson/) for the full hardware-interfaces and flashing documentation for each product.
